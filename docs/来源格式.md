# 设施巡检资料来源格式

输入为 FlatGeobuf 3.x 单文件，使用 FlatBuffers header、packed Hilbert R-tree 和长度前缀 feature。支持 Point、LineString、Polygon、MultiPolygon，坐标为平面米制，无曲线；范围参数为闭合矩形 [minX,minY,maxX,maxY]，边界接触算相交，洞内不算。header 的 indexNodeSize=0 表示无索引。支持 HTTP Range 及 If-Match；ignored-range 返回200全文件，changed 场景 ETag 在二次读取时改变。每条输出保留 feature id、属性及命中的几何依据，coverage 记是否索引裁剪和读取字节。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

格式参考：https://flatgeobuf.org/。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
